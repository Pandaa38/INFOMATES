{\footnotesize\ttfamily int main (\begin{DoxyParamCaption}\item[{int}]{argc,  }\item[{char $\ast$}]{argv\mbox{[}$\,$\mbox{]} }\end{DoxyParamCaption})}

This program learns a \mbox{\hyperlink{classProfile}{Profile}} model from a set of input DNA files (file1.\+dna, file2.\+dna, ...). The learned \mbox{\hyperlink{classProfile}{Profile}} object is then zipped (kmers with any missing nucleotide or with frequency equals to zero will be removed) and ordered by frequency and saved in the file output\+Filename (or output.\+prf if the output file is not provided).

Running sintax\+: \begin{quote}
LEARN \mbox{[}-\/t$\vert$-\/b\mbox{]} \mbox{[}-\/k k\+Value\mbox{]} \mbox{[}-\/n nucleotides\+Set\mbox{]} \mbox{[}-\/p profile\+Id\mbox{]} \mbox{[}-\/o output\+Filename\mbox{]} $<$file1.\+dna$>$ \mbox{[}$<$file2.\+dna$>$ $<$file3.\+dna$>$ ....\mbox{]} \end{quote}
~\newline
 Running example\+: \begin{quote}
LEARN -\/k 2 -\/p bug -\/o /tmp/unknown\+ACGT.prf ../\+Genomes/unknown\+ACGT.dna \end{quote}
~\newline
 \begin{quote}
cat /tmp/unknown\+ACGT.prf \end{quote}
MP-\/\+KMER-\/\+T-\/1.\+0 bug 7 GG 2 AC 1 AG 1 AT 1 CC 1 GA 1 TA 1
