{\footnotesize\ttfamily const string VALID\+\_\+\+NUCLEOTIDES\+\_\+\+ADN = \char`\"{}ACGT\char`\"{}}

This program reads and normalizes an undefined number of \mbox{\hyperlink{classProfile}{Profile}} objects from the input files passed as parameters to main(). These normalized \mbox{\hyperlink{classProfile}{Profile}} objects are used to obtain the union of them, the join \mbox{\hyperlink{classProfile}{Profile}}. The join \mbox{\hyperlink{classProfile}{Profile}} is then zipped (pairs with frequency less or equals to zero are deleted) and sorted by decreasing order of frequency. In that order, if there is any tie in frequencies, then alphabetical order of kmers is applied. Finally, the resulting sorted \mbox{\hyperlink{classProfile}{Profile}} is saved in the output file. The program must receive at least an input file and an output file. The output \mbox{\hyperlink{classProfile}{Profile}} will have as profile identifier, the one of the first input file ($<$file1.\+prf$>$). If an input file $<$file$\ast$.prf$>$ has a profile identifier different from the one of the first file ($<$file1.\+prf$>$), then it will not be included in the union.

Running sintax\+: \begin{quote}
kmer2 $<$output\+File.\+prf$>$ $<$file1.\+prf$>$ \mbox{[}$<$file2.\+prf$>$ ... $<$filen.\+prf$>$\mbox{]} ~\newline
 \end{quote}
~\newline
 Running example\+: \begin{quote}
kmer2 /tmp/output\+File.prf ../\+Genomes/5pairs\+RNA.prf ../\+Genomes/6pairs\+RNA.prf \end{quote}
