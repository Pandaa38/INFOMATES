{\footnotesize\ttfamily int main (\begin{DoxyParamCaption}\item[{int}]{argc,  }\item[{char $\ast$}]{argv\mbox{[}$\,$\mbox{]} }\end{DoxyParamCaption})}

This program reads an undefined number of \mbox{\hyperlink{classProfile}{Profile}} objects from the set of files passed as parameters to \mbox{\hyperlink{main_8cpp_a0ddf1224851353fc92bfbff6f499fa97}{main()}}. All the Profiles object, except the first one, must be stored in a dynamic array of \mbox{\hyperlink{classProfile}{Profile}} objects. Then, for each \mbox{\hyperlink{classProfile}{Profile}} in the dynamic array, this program prints to the standard output the name of the file of that \mbox{\hyperlink{classProfile}{Profile}} and the distance from the first \mbox{\hyperlink{classProfile}{Profile}} to the current \mbox{\hyperlink{classProfile}{Profile}}. Finally, the program should print in the standard output, the name of the file with the \mbox{\hyperlink{classProfile}{Profile}} with the minimum$\vert$maximum distance to the \mbox{\hyperlink{classProfile}{Profile}} of the first file and its profile identifier.

At least, two \mbox{\hyperlink{classProfile}{Profile}} files are required to run this program.

This program assumes that the profile files are already normalized and sorted by frequency. This is not checked in this program. Unexpected results will be obtained if those conditions are not met.

Running sintax\+: \begin{quote}
kmer3 \mbox{[}-\/t min$\vert$max\mbox{]} $<$file1.\+prf$>$ $<$file2.\+prf$>$ \mbox{[} ... $<$filen.\+prf$>$\mbox{]} \end{quote}
~\newline
 Running example\+: \begin{quote}
kmer3 ../\+Genomes/human1.prf ../\+Genomes/worm1.prf ../\+Genomes/mouse1.prf \end{quote}
Distance to ../\+Genomes/worm1.prf\+: 0.\+330618 Distance to ../\+Genomes/mouse1.prf\+: 0.\+224901 Nearest profile file\+: ../\+Genomes/mouse1.prf Identifier of the nearest profile\+: mus musculus

Running example\+: \begin{quote}
kmer3 -\/t max ../\+Genomes/human1.prf ../\+Genomes/worm1.prf ../\+Genomes/mouse1.prf \end{quote}
Distance to ../\+Genomes/worm1.prf\+: 0.\+330618 Distance to ../\+Genomes/mouse1.prf\+: 0.\+224901 Farthest profile file\+: ../\+Genomes/worm1.prf Identifier of the farthest profile\+: worm
