{\footnotesize\ttfamily int min\+\_\+dist (\begin{DoxyParamCaption}\item[{const double $\ast$}]{distances,  }\item[{int}]{size }\end{DoxyParamCaption})}

This program prints the profile identifier of the closest profile model for an input DNA file ($<$file.\+dna$>$) among the set of provided models\+: $<$profile1.\+prf$>$, $<$profile2.\+prf$>$, ... The program uses the \mbox{\hyperlink{classKmerCounter}{Kmer\+Counter}} class to obtain a \mbox{\hyperlink{classProfile}{Profile}} for the input file $<$file.\+dna$>$. That \mbox{\hyperlink{classProfile}{Profile}} should be zipped, to eliminate kmers with any missing nucleotide, and sorted in decreasing order of frequency of kmers. After that, the program compares the learned \mbox{\hyperlink{classProfile}{Profile}} with the ones provided by the arguments $<$profile1.\+prf$>$ \mbox{[}$<$profile2.\+prf$>$ $<$profile3.\+prf$>$ ....\mbox{]} It classifies the input DNA file with the identifier of the \mbox{\hyperlink{classProfile}{Profile}} with a minor distance.

This program assumes that the profile files are already normalized and sorted by frequency. This is not checked in this program. Unexpected results will be obtained if those conditions are not met.

Running sintax\+: \begin{quote}
CLASSIFY \mbox{[}-\/k k\+Value\mbox{]} \mbox{[}-\/n nucleotides\+Set\mbox{]} $<$file.\+dna$>$ $<$profile1.\+prf$>$ \mbox{[}$<$profile2.\+prf$>$ $<$profile3.\+prf$>$ ....\mbox{]} \end{quote}
